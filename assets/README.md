# 资源目录说明

本目录用于放置运行所需的大型资源文件，**这些文件不纳入 Git 版本控制**。

## 需要手动放置的资源

### 1. Blender 程序
将 Blender 程序目录放置于项目根目录的 `blender/` 下：
```
YOLO-splice/
  blender/
    blender.exe
    ...
```

### 2. 缺陷模型库
将 `排水管道内缺陷模型库1.0/` 复制到本目录：
```
YOLO-splice/
  assets/
    排水管道内缺陷模型库1.0/
      ...
```

### 3. 井室模板库
将 `排水管道井室模板库1.0/` 复制到本目录：
```
YOLO-splice/
  assets/
    排水管道井室模板库1.0/
      标准矩形井室0.6.glb
      ...
```

## 配置引用

`config/splice.yaml` 中的路径已默认指向 `./assets/` 下的位置，放置资源后无需修改配置即可运行。
